### Proceso de Iteración para la Creación del Prompt Final

#### Paso 1: Prompt Versión 1 (Básico)
```text
Crea un ejercicio de Java sobre condicionales para estudiantes.
# Tarea: Mi prompt profesional

## Funcionalidad elegida
Generación de un ejercicio académico práctico en Java sobre estructuras de control condicionales (`if-else` y `switch`) orientado a estudiantes principiantes.

## Version 1: prompt basico
Crea un ejercicio de Java sobre condicionales para estudiantes.

## Version 2
Actúa como docente de Java y crea un ejercicio práctico sobre condicionales if-else y switch para estudiantes principiantes.

## Version 3: prompt final
Actúa como un docente de programación Java. Crea un ejercicio práctico sobre estructuras de control condicionales (if-else y switch) orientado a estudiantes principiantes. El ejercicio debe incluir:
1. Un enunciado claro con un escenario del mundo real.
2. Requisitos específicos de entrada y salida.
3. Una solución completa en Java con comentarios explicativos.
Presenta la respuesta organizada en secciones claras usando formato Markdown.

## Componentes del prompt final
- **Rol:** Docente de programación Java.
- **Tarea:** Crear un ejercicio práctico sobre condicionales (`if-else` y `switch`).
- **Público Objetivo:** Estudiantes principiantes.
- **Instrucciones específicas:** Incluir caso del mundo real, entradas/salidas y solución comentada.
- **Formato de salida:** Estructurado en Markdown.

## Evaluacion del resultado

| Criterio | Cumple (Sí / No) |
|---|---|
| ¿El rol asignado (docente de Java) es claro? | Sí |
| ¿El ejercicio trata sobre condicionales (`if-else` / `switch`)? | Sí |
| ¿Incluye escenario del mundo real y requisitos de entrada/salida? | Sí |
| ¿Proporciona el código Java completo y comentado? | Sí |
| ¿La respuesta está bien estructurada con Markdown? | Sí |

## Errores que evite
- **Prompt impreciso:** Evité pedir un "ejercicio en general" sin indicar el tema técnico exacto (`if-else` y `switch`).
- **Falta de contexto:** Evité ejercicios abstractos exigiendo un escenario del mundo real.
- **Falta de estructura:** Evité respuestas desordenadas al exigir el uso explícito de Markdown y secciones delimitadas.
- **Código incompleto:** Evité que la IA entregara solo fragmentos exigiendo la solución completa y comentada.
